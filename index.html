MOODIFY

AI Powered Facial Emotion Based Music Recommendation System

Problem Statement

Many users struggle to find music that matches their emotional state. Moodify solves this by using facial emotion detection to recommend personalized songs.

System Methodology

Dataset: Facial Emotion Dataset (FER-2013)
Model: CNN (Convolutional Neural Network)
Integration: Spotify API

Results & Analysis

Model Accuracy: 89%
